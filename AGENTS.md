## Safety rules for Codex

- TUYET DOI KHONG duoc chay cac lenh sau:
  - git reset --hard
  - git clean -fdx
  - git push --force
  - rm -rf, del /s, move /y
- Chi duoc de xuat patch (diff), luon hoi toi truoc khi ap dung thay doi.
- Voi repo nay, hay xem nhu read-only: khong tu y sua file, chi review, giai thich va sinh code mau.
